## Getting Started

Each example is self-contained with its own README and dependencies. Navigate to the example directory for setup instructions.

### Prerequisites

- Node.js 20+
- A Linq API token ([sign up](https://linqapp.com))
- Webhook endpoint (use [ngrok](https://ngrok.com) for local development)
