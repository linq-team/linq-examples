# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it responsibly.

**Do not open a public issue for security vulnerabilities.**

Instead, please email security@linqapp.com with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

We will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for critical issues.

## Scope

This repository contains example code and reference implementations. While we take security seriously, please note:

- These examples are for educational purposes
- They may not include all production security hardening
- Always review and adapt code for your specific security requirements

## Supported Versions

We provide security updates for the latest version of each example only.
